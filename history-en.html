Version history

1.1 build 1 (upcoming · in development)

  • Playback: resuming after switching scores no longer plays the previous score; a single playback instance (fixes the real-device "two sounds at once")
  • Engraving: beams no longer overlap noteheads, beam groups are split at a 2-octave pitch span (no more crossed stems), and a mid-measure time signature reserves space by its measured glyph width
  • Engraving: a batch of wrong music-font code points was fixed (checked against the official SMuFL glyph-name table) — Segno / D.S. / D.C. drew the wrong mark (Segno showed D.C.), tempo marks showed the wrong note value (♩ = 120 was drawn as a whole note), the pedal release mark and the "✱" mark, swapped staccato / tenuto icons, the arpeggio wiggle, and the 15mb/8va bass clefs; a new Tools/FontGlyphCheck guard prevents a recurrence
  • Engraving: mordent glyphs settled against MuseScore 3.6.2 / 4.2.1 renders (<mordent> = with the vertical stroke, <inverted-mordent> = without), and the details panel's Chinese "上波音 / 下波音" labels now match the glyph and the explanation
  • MusicXML: Roman-numeral chords and inversions (<function>, with super/subscript figures) are parsed, displayed and exported; the exporter's schema violations are cleared (dacapo attribute name, <measure-repeat> instead of the invalid <percent>, notations element order …); all six scores now round-trip byte-identically on the first pass
  • Terminology aligned with MuseScore's Chinese wording («和弦记号» …), English added for the Shortcuts intents
  • The sound bank is now a compressed .sf3 (≈14 MB, decoded locally on first launch): the download drops from ≈134 MB to ≈13 MB
  • Experimental features are labelled as such (jianpu, coverage score); the repeats score was redesigned into four single-theme scores (repeats & endings / measure & beat repeats / D.S. & Coda / D.C. & Fine)
  • Requires iOS 16.0+, iPhone / iPad

1.0 build 8 (previous production)

  • First public release: open MusicXML (.xml/.musicxml/.mxl) and vector PDFs, Bravura engraving, a bundled GM sound bank for offline playback, transport (return to start / pause & resume / play from the selected note), note details + music classroom, metronome / tempo / loop / swing, scale practice and a piano roll, export to PDF / PNG / MIDI / WAV / MusicXML, Chinese and English, fully offline
  • The bundled GM sound bank was the uncompressed .sf2 (≈148 MB), which is why the download was large
  • Build history: build 6 was submitted and withdrawn; builds 7 / 8 were archived but never uploaded
